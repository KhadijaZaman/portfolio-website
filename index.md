## AI search visibility, and the SEO that makes it land

Getting a brand cited inside ChatGPT, Gemini, Perplexity and AI Overviews is the job. Semantic SEO, content architecture and automation are what make the citations arrive and keep arriving.

01

### AI Search Visibility (GEO / AEO)

Entity frameworks built from Google's query fan-out patent and Koray Tuğberk's semantic model, so content is structured the way retrieval systems select and quote it. Grounded versus non-grounded citation experiments that track explicit citations and implicit brand mentions separately, because they move independently. Free tools built as LLM entry points, answers placed where models read (Reddit, Quora, G2), and LLM referral traffic segmented in GA4 so the result is measured, not assumed.

The method is public: [the retrieval-readiness checklist](/blog/get-cited-by-ai-search/), [how SEO, AEO and GEO sequence](/blog/geo-aeo-vs-seo/), and [the study I tried to break](/blog/breaking-my-own-study/).

02

### Semantic & Technical SEO

What gets a page retrieved in the first place: site architecture, crawl and indexation governance, schema, Core Web Vitals, and the semantic coverage that makes a domain the obvious source on its topic.

03

### Content Architecture

Topic clusters and intent mapping built for how models interpret authority, so a site earns citations across a topic rather than on one lucky page.

04

### Measurement & Automation

Python, BigQuery and n8n pipelines that pull GA4 and Search Console data, segment LLM referrals, and report without anyone exporting a spreadsheet. Auditable, so a number can be checked.
