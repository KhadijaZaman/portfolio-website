# Query Fan-Out Explorer

Search engines and LLMs don't answer your query — they fan it out into dozens of sub-queries and synthesize the results. This explorer groups its expansion into the five sub-query types described in Google's query fan-out patent research (related, implicit, comparative, recent, personal), so you can see the questions your content needs to cover to be retrieved and cited.

## What is query fan-out?

Query fan-out is the step where Google's AI search and large language models expand one query into many related sub-queries before assembling an answer, as described in Google's query fan-out patent research. This free explorer groups a seed query's expansion into the five sub-query types named in that research: related, implicit, comparative, recent and personal.
