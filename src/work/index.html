◆ How it started

Before the tool existed there was a 94-day query fan-out experiment I ran with Wellows COO Muhammad Saleem Ahrar. He posted the before-and-after publicly:

  • 923 → 2.12K clicks
  • 62.9K → 626K impressions

Google Search Console, the fan-out experiment pages only — 11 Aug–12 Nov 2025 against the prior 94 days. A different scope from the site-wide Wellows figures in the case study above.

We turned the method into a free tool so other practitioners could apply it directly — and that is the tool Search Engine Land picked up.
